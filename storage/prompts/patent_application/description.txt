# Промпт "description.txt"

Демонстрационная заглушка. Реальный текст промпта составляет интеллектуальную
собственность проекта и поставляется отдельно.

Формат: Python-шаблон `.format(**variables)`. Доступные переменные задаются
билдером соответствующего пайплайна (см. `app/service/*/raw_data_generator`).

Порядок подключения: положить файл с тем же именем в каталог из
`config.yaml -> storage.prompt_dir` и указать относительный путь в
`storage.*_prompt_path`.

Ожидаемые переменные для этого промпта:

- `{appointment}`
- `{technical_area}`
- `{technical_result}`
- `{construction}`
- `{operation_principle}`
- `{parts}`
- `{analog_data}`
- `{analog_id_rospatent}`
- `{figures}`
